# 🌐 Cyberpunk & Terminal Temalı İnteraktif Portfolyo

Bu proje, **Fatmanur Sena Bülbül**'ün (Malware Analyst / Siber Güvenlik Uzmanı) profesyonel geçmişini, projelerini, teknik yeteneklerini ve siber güvenlik raporlarını sergilediği fütüristik, siberpunk ve terminal temalı interaktif bir portfolyo web sitesidir. 

Site; neon yeşil tonları (`#00ff41`), tarama çizgileri (scanlines) efekti, siber matris animasyonları ve derinlik hissi veren dinamik kamera sarsıntıları/açılarıyla gerçek bir hacker terminali veya siber güvenlik arayüzü hissi uyandıracak şekilde tasarlanmıştır.

---

## 🚀 Özellikler

- **Giriş (Intro) Ekranı:** Açılışta kullanıcıyı karşılayan ve siber evrene geçiş hissi veren, atlanabilir (`Skip`) etkileyici bir Canvas animasyonu.
- **İki Dilli Destek:** LocalStorage entegrasyonu ile Türkçe ve İngilizce dil seçeneği hafızada tutulur.
- **İnteraktif 3D Panel Düzeni:** Merkezdeki profil fotoğrafının etrafında 8 farklı başlığa ayrılmış simetrik bilgi panelleri yer alır. Fare hareketine duyarlı 3D kamera açıları sunar.
- **Detay Katmanları (Double Overlay Panel):** Panellere tıklandığında açılan pencereler ve bu pencerelerin içinden de daha derin detaylara (örneğin staj veya proje ayrıntılarına) dallanan 2. katman modallar.
- **GitHub & Rapor Entegrasyonu:** Geliştirilen siber güvenlik projelerinin dillerine göre renklendirilmiş şık kartlar halinde listelenmesi.
- **Tam Mobil Uyumluluk:** Mobil cihazlarda dokunmatik kaydırma (`touch-action`) özellikleri gözetilerek optimize edilmiş dikey akış düzeni.
- **Paskalya Yumurtaları (Easter Eggs):** Kodun en başında (`` yorum satırlarında) Nazım Hikmet şiiri, Doc Hudson & Lightning McQueen replikleri ve ASCII sanatıyla işlenmiş özel bir karşılama metni bulunur.

## 🗂️ Portfolyo Bölümleri (Bilgi Panelleri)

Site üzerinde interaktif olarak gezilebilen 8 ana modül bulunur:
1. **01 // EĞİTİM (EDU):** Uludağ Üniversitesi Bilgisayar Programcılığı geçmişi ve akademik detaylar.
2. **02 // DENEYİM (EXP):** İnegöl Belediyesi, Meram Belediyesi stajları ve Anticverse topluluk temsilciliği gibi sektörel deneyimler.
3. **03 // PROJELER:** Web3 hackathon projesi (EchoBlade), emlak asistanı uygulaması (OpenHaven Rental) gibi teknik işler.
4. **04 // YETENEKLER (SKILLS):** IDA Pro, x64dbg, Wireshark, Burp Suite gibi siber güvenlik araçlarının yetkinlik seviyeleri.
5. **05 // SERTİFİKALAR (CERTS):** freeCodeCamp Web Tasarımı, Siber Kulüpler Birliği Sızma Testi eğitimleri vb.
6. **06 // REFERANSLAR (REFS):** Akademik danışmanlar ve mentorlardan alınan referanslar.
7. **07 // TASARIM (DESIGN):** Tipografi, logo, poster ve dijital yaratıcı çalışmalar.
8. **08 // RAPORLAR (REPORTS):** Tersine mühendislik süreçleri ve Aurotun Stealer gibi zararlı yazılımların statik/dinamik analiz raporları.

## 🛠️ Kullanılan Teknolojiler

- **HTML5:** Yapısal içerik, anlamsal etiketler ve gömülü şablonlar.
- **CSS3 (Modern Efektler):**
  - CSS Custom Properties (Değişkenler)
  - CSS 3D Transforms & Perspective (Derinlik efektleri için)
  - Conic & Linear Gradients (Dönen profil çerçeveleri ve grid arka plan için)
  - `@keyframes` animasyonları (Tarama çizgileri ve nabız efektleri)
- **Pure JavaScript (ES6+):** Harici kütüphane bağımlılığı olmadan (Vanilla JS) geliştirilmiş animasyon yönetimleri, LocalStorage işlemleri, dinamik DOM manipülasyonu ve modal pencere akışları.
- **Google Fonts:** Siber temayı destekleyen *Share Tech Mono*, *Orbitron* ve *Rajdhani* font aileleri.
